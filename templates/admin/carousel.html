How it works
  • Search and select any movie from your database to add it to the carousel.
  • Upload a poster image (JPG/PNG/WebP, max 5 MB) or paste an image URL.
  • Paste a YouTube Trailer URL — a "Watch Trailer" button will appear on the homepage.
  • Set Display Order (lower = appears first). Toggle slides on/off without deleting.
  • If no slides are active, the site automatically shows top-rated movies.
